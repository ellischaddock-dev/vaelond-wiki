# Using this Obsidian vault

1. Unzip the folder.
2. In Obsidian, choose **Open folder as vault**.
3. Select the `Vaelond Player Guide` folder.
4. Open [[index]].

The vault uses ordinary Markdown files and Obsidian `[[internal links]]`. Images are stored in `_Assets`. The current migration includes the world map, Rakaran regional influence map, clan and civic sigils, Somnolent’s town map, a full campaign chronicle through Session 19, campaign-reference pages, 21 notable/deceased portraits, five bastion-staff cards, five horse cards, three faction symbols and three recovered document images, the Anthea Bloodclot death report and a reconciled campaign tracker through Session 19.

## Recommended Obsidian setting

Under **Settings → Files and links**, set **Default location for new attachments** to `In the folder specified below`, then choose `_Assets`.

## Publishing note

Player-facing lore sits in the numbered folders. Administrative migration records and templates are stored in `_Admin` and `_Templates`; exclude those folders from a public Quartz build.

The [[Rootbound]] page now distinguishes common knowledge from evidence uncovered by the party and is marked `status: published`.

Keep unrevealed DM information in a separate private vault or repository rather than hiding it in unpublished pages within this player vault.
